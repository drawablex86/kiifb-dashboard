# Research Data Directory — KIIFB Accountability & Public Value Dashboard

This directory contains research assets, raw source documents, extracted tables, normalised datasets, and derived metrics used by the KIIFB Dashboard.

## 1. Directory Structure

```text
data/
├── raw/                      # Immutable original source documents
│   ├── committee-report/     # Official Expert Committee Report PDFs & extracts
│   ├── kiifb/                # KIIFB project registers, annual reports, GIS snapshots
│   ├── kite/                 # KITE education infrastructure records & school directories
│   ├── kiidc/                # KIIDC project records & status reports
│   ├── state-planning-board/ # Economic Reviews, Development Reports
│   └── government-and-legal/ # Legislation, CAG reports, Supreme Court orders, GOs
├── processed/                # Cleaned, structured, normalized datasets (JSON/CSV)
├── derived/                  # Analytical metrics, calculated ratios, scenario outputs
├── manifest.json             # Cryptographic inventory of all acquired sources
└── README.md                 # This documentation
```

## 2. Research Integrity & Ingestion Rules

1. **Raw Files Are Immutable**:
   - Files stored in `data/raw/` must never be modified or overwritten.
   - If an updated snapshot or document is acquired, archive it in a dated subfolder (e.g. `data/raw/kiifb/2026-10-16/`).
2. **Every Source Registered in `manifest.json`**:
   - Every file must have an entry containing: `source_id`, `title`, `publisher`, `original_url`, `retrieval_date`, `sha256`, `local_path`, and `licence_or_terms`.
3. **Reproducibility**:
   - Every file in `data/processed/` or `data/derived/` must be generated by a documented script in `scripts/` with deterministic logic.
   - Preserves source units (`₹ Crore`, `₹ Lakh`) alongside normalised standard numbers.
